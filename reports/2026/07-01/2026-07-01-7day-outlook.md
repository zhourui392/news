## 10. 凯利仓位校准（风险预算上限，非交易信号）

> 凯利在此仅用作"仓位刹车 / 风险预算上限"，不是机械买卖指令。胜率 p 由第 5 节情景概率解释性合成，G/L 来自本报告价格与失效条件假设，均为约数与区间。

**交易假设 A：非农落地后（07-02 数据公布后）轻仓做多 AI 应用/云平台层（Meta / AWS 概念 / 大盘科技 ETF，非半导体）**
- **方向**：做多；**适用前提**：非农不超强（时薪 ≤0.3%）、10Y 守 4.5 下方、SOX 次日不再大跌、Meta 不出现大幅回吐（例如 5%+）。对应 Base 内偏多路径（约 45% 中 25pp 有利）+ Bull（25pp 中约 20pp 兑现该方向）。
- **胜率估计 p ≈ 0.50**（有利 45pp / 全部合计 100，扣除 Base 内震荡走平和假突破实际可赚约 50%）；败率 q ≈ 0.50。
- **目标收益 G ≈ +3%~+5%**（Meta 续势 + AI 应用主题延续），止损 L ≈ **-2.5%**（Meta 破关键均线 / QQQ 跌破 07-01 收盘对应值-2.5%）。**盈亏比 b ≈ 1.4**。
- **原始凯利 f\* = (b×p − q)/b = (1.4×0.50 − 0.50)/1.4 = (0.70 − 0.50)/1.4 ≈ 0.14**（14% 风险预算上限）。
- **实际建议：≤1/4 Kelly ≈ 3.5% 风险预算**；07-02 非农为跳空事件，**数据公布前不启用凯利**，仅可用 1/8 Kelly ≈ 1.75% 试探（并接受该仓位可能跳空止损失效）。

**交易假设 B：半导体（SOX / 美光 / 闪迪）做空反弹**
- **方向**：做空反弹（不裸空、需等技术性反弹到位）；**适用前提**：SOX 反弹至 13800 附近但未收复 14000 / 美光反弹至 -6% 附近未破 -3%；保证金债务拐点未确认。对应 Bear② 独立路径（30pp 中约 15pp）+ Base 内半导体寻底（45pp 中约 15pp）。
- **胜率估计 p ≈ 0.48**（Bear② 是新增/独立路径、但存在"一日出清"可能）；败率 q ≈ 0.52。
- **目标收益 G ≈ +3%~+5%**（SOX 二次下探至 12500–12800），止损 L ≈ **-2.5%**（SOX 反收复 14200 = 06-30 高点上方）。**盈亏比 b ≈ 1.4**。
- **原始凯利 f\* = (1.4×0.48 − 0.52)/1.4 = (0.672 − 0.52)/1.4 ≈ 0.11**（11% 风险预算上限）。
- **实际建议：因胜率优势不明显（48% < 50%）、且反向操作对散户止损纪律要求高，本期倾向 1/8 Kelly ≤ 1.5%**，或直接用 SOXS/SOXX 认沽期权替代裸空。

**交易假设 C：轻仓做多黄金（现货或 GLD）**
- **方向**：做多；**适用前提**：4050 以下入场、非农不出超强、10Y 不破 4.55、多哈会谈无破裂性反转。

- **实际建议：1/4 Kelly ≈ 5% 风险预算**。**注意**：黄金已在沃什讲话后急拉 +2.6%，短线追涨风险大，**建议等回踩 4050–4080 再启用**，不宜今日尾盘/明日开盘直接高开追。

**风险预算 vs 名义仓位**：以上 f\* 是"该方向可承受的风险预算上限"（即愿为此方向承担的最大回撤占账户比例），**不是买入账户某百分比的机械指令**。换算名义仓位须按止损距离折算：名义仓位 ≈ (风险预算 × 账户) / 止损百分比。例：假设 A 中 3.5% 风险预算 / 2.5% 止损 → 名义敞口约为账户的 1.4 倍（意味着若使用 1x 现货 QQQ 就已经用光风险预算、无杠杆余量）。

**不启用凯利的情形（本期需特别警惕）**：
- **07-02 非农数据公布前**——止损极易因跳空失效，凯利不适用，建议等数据落地后再启用；
- **假设 A 与 C 高度相关**（都受益于"利率下 + 美元弱"）——须按相关性合并计算、不可各自独立满仓；假设 B 与 A 反向相关，可作为对冲但不可同时"全上"；
- 若情景概率重新分布使 Bear 升至主导（如非农超强 >+15 万、10Y 破 4.55、SOX 次日再 -3%）→ 假设 A/C 的 p 迅速塌到 <0.40、凯利转负 → **立即停用并反向减仓**；
- 假设 B 因胜率优势不显著（p=0.48 < 0.50），本期**不单独强推**，倾向用期权替代或直接放弃。

**凯利校准失效条件**：非农 + 戴利 + FOMC 纪要中任一强化鹰派 → 收益率与美元共振上行；霍尔木兹关闭致油价跳涨；SOX 再次日 -3%+ 引发系统性风险传导；Meta/META 出现 5%+ 单日回吐 → 上述 p、G、L 假设**全部失效**，须重算或清零。
