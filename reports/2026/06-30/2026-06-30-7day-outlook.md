## 5. 情景树（base / bull / bear）

### 🔵 基准情景 Base —— 概率 50%

- **资产方向**：道指 ↔/↗（温和），标普 ↗（小幅），纳指 ↗（领先），美元 ↔，美债收益率 ↔（10Y 4.35–4.50 区间），油 ↘/↔，金 ↔。
- **失效信号**：非农或时薪显著偏离预期；10Y 单日跳升破 4.50；中东突发航道关闭。

### 🟢 乐观情景 Bull —— 概率 28%
- **触发条件**：非农偏软但不崩（<+90K、失业率持稳 4.3–4.4%、时薪≤0.3%），强化"高利率更久但不再加息、年内仍可能转松"预期；美元、收益率回落；AI 成本下降（OpenAI）+ 存储超级周期 + 目标价上调共振；VIX 续创低、多哈会谈传出积极信号。
- **资产方向**：纳指 ↑↑（领涨），标普 ↑，道指 ↑（跟随，金融企稳是前提），美元 ↘，美债收益率 ↘，油 ↘，金/银 ↗（实际收益率回落）。
- **失效信号**：收益率不跌反升（"软数据=滞胀"被定价）；杠杆/保证金平仓引发科技股急跌。

### 🔴 悲观情景 Bear —— 概率 22%
- **触发条件**（二选一即可）：① 非农超强（>+160K）或时薪 >+0.4% mom → 验证哈玛克/沃什鹰派、加息预期升温、10Y 上破 4.50 甚至向德银 4.80% 目标靠拢、美元反弹 → 高估值 AI 股估值压缩 + 拥挤平仓 + 保证金去杠杆；② 中东：多哈会谈破裂或革命卫队关闭霍尔木兹 → 油价跳涨 → 通胀+避险双杀。
- **资产方向**：纳指/SOX ↓↓（跌幅最大），标普 ↓，道指 ↓（相对抗跌），美元 ↑（情景①）或 ↔（情景②），美债收益率 ↑（①）/↘避险（②），油 ↓（①）/↑↑（②），金 ↗（避险）。
- **失效信号**：数据落地后收益率回落、美元转弱；中东快速恢复谈判。

> 概率权重依据：今日实际收盘强势且 VIX 走低、美元回落，说明 risk-on 当前占优 → base 偏多权重最高(50%)；bull 受"非农需偏软+收益率配合"双重条件约束(28%)；bear 因 NFP 强数据 + 中东尾部两条独立触发路径而保留较高尾部概率(22%)。

## 10. 凯利仓位校准（风险预算上限，非交易信号）

> 凯利在此仅用作"仓位刹车 / 风险预算上限"，不是机械买卖指令。胜率 p 由第 5 节情景概率解释性合成，G/L 来自本报告价格与失效条件假设，均为约数与区间。

**交易假设 A：非农落地后（≥07-02 数据公布）轻仓做多 AI/半导体强势链条（纳指/SOX 篮子）**
- 方向：做多；适用前提：非农不超强、收益率守 4.50 下方、AI 消息流延续（Base 偏多 + Bull 情景，合计约 78% 的非 Bear 概率中、对该方向有利的部分）。
- 胜率估计 p ≈ **0.52**（base 中偏多胜率 + bull 兑现，扣除 base 内震荡走平与假突破）；败率 q ≈ 0.48。
- 目标收益 G ≈ **+4%~+6%**（SOX 续势、纳指趋势延续），止损 L ≈ **-3%**（SOX 跌破 13700 / 纳指跌破 25800）。盈亏比 b = G/L ≈ **1.5**。
- 原始凯利 f* = (b×p − q)/b = (1.5×0.52 − 0.48)/1.5 = (0.78 − 0.48)/1.5 ≈ **0.20（20% 风险预算上限）**。
- **实际建议：分数凯利。** 因 07-02 非农为跳空事件、且纳指/SOX/AI 多标的高度同向（相关性高），实际应取 **1/4 Kelly 以下（约 ≤5% 风险预算），并建议把启用时点放在非农数据落地之后**；数据公布前不启用或仅用 1/8 Kelly（约 2.5%）试探。

**交易假设 B：轻仓做多道指篮子**
- 方向：做多；前提：金融股企稳、油价不跳涨。
- p ≈ 0.50、b ≈ 1.2 → f* = (1.2×0.50 − 0.50)/1.2 ≈ **0.083（8% 上限）**，1/4 Kelly ≈ 2%。
- **判定：边际优势不明显（道指受金融股拖累、弹性弱于纳指），本期对假设 B 倾向不单独启用凯利，归入"观望/极轻仓跟随"。**

**风险预算 vs 名义仓位**：以上 f* 是"该方向可承受的风险预算上限"（即愿为此方向承担的最大回撤占账户比例），**不是买入账户某百分比的指令**。换算名义仓位须按止损距离折算：名义仓位 ≈ (风险预算 × 账户) / 止损百分比——例如 5% 风险预算、3% 止损距离 → 名义敞口约为账户的 1.6 倍杠杆当量，须再受个人杠杆上限与风险承受能力约束下调。

**不启用凯利的情形（本期需特别警惕）**：
- 07-02 非农**数据公布前**——止损极易因跳空失效，凯利不适用，应等数据落地；
- 多个交易标的高度相关（纳指/SOX/AI 同向）——须按相关性下调或合并风险预算，不可各自满仓；
- 若情景概率重新分布使 Bear 升至主导（如非农超强、10Y 破 4.5），该方向凯利转负 → **立即停用并反向减仓**；
- 假设 B（道指）胜率优势不明显，盈亏比缺乏可靠依据，本期不强行计算名义仓位。

**凯利校准失效条件**：非农/沃什/ISM 组合推动收益率与美元共振上行、霍尔木兹关闭致油价跳涨、或科技股放量去杠杆——任一出现，则上述 p、G、L 假设全部失效，须重算或清零。
