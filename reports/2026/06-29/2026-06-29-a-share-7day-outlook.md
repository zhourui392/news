## 为什么会有影响（因果链）

**链 1：地缘事件降温 → 油价回吐 → 通胀预期降温 → 估值修复**
WTI 70.27 → 69.37 / 黄金 4050 / 白银 58.20 / 富时 A50 +0.3% 这条链已经在亚洲早盘**走完一遍**。地缘溢价的撤回直接削弱**炼化/油运/军工短期催化**，但**为 A 股大盘提供风险偏好托底**。失效信号：周二多哈会谈破裂 / 普京柴油禁运正式落地 / 沙特/委内瑞拉新的供应中断。

**链 2：韩股半导体抛售 → A 股 AI/芯片 → 拥挤度 + 估值压制**
KOSPI -3% + 三星 -5% + SK 海力士 -4.5% + KOSDAQ 熔断是 6/26 SOX -5.29% 的"亚洲版二次定价"。A 股芯片/光通信/HBM 配套**第一小时大概率 -3% 至 -5%**。**但**：① 1.3 万亿美元投资官宣是积极对冲；② 中金/华泰研报已在"AI 上游卖铲子"建议加仓；③ 拥挤度修复后**中报预增**（半导体材料、设备、电子化学品）可能是新的弹性方向。

**链 3：央行隔夜逆回购首日 → 短端利率 → 红利/银行风格**
今天 OMO 公告**首次公布隔夜逆回购利率**——若 1.30–1.35% 是宽货币明确信号 → **银行、保险、煤炭、电力公用、白酒**等红利风格估值修复 + 国债期货走强。若维持 1.40% 是中性。失效信号：央行投放规模低于预期 + 6/30 跨季 DR007 大幅冲高。

**链 4：人民币 + 短端利率 → 北向资金 → 港股**
A50 期指 +0.3% 高开已经把人民币贬值预期定价掉一部分。**离岸 HIBOR 一周期 1.70%**（5 月新高）的边际紧绷可能在央行新工具下缓解。北向单周**预计净流出 -50 至 -120 亿**（比 6/26 报告的 -150 亿温和）。

**链 5：美联储鹰派 + BIS 警告 → 美元 / 全球估值压制**

**链 7：融资余额先行回落 + 北证 50 独立行情 → 资金结构改善**
融资余额 -205.97 亿（截至 6/26）+ 北证 50 周五逆势 +2% → 杠杆资金已先减仓 + 增量资金转向小盘/题材独立运行。**资金面已经为外盘冲击吸收了一部分压力**。
