## 3️⃣ 当前主线综合判断

### 主线 1：美伊军事冲突升级（从"谈判僵持"到"封锁 + 跨境打击"）

- **方向**：极度利空风险偏好
- **强弱程度**：9/10（边际变化极大）
- **最近一周一致性**：高度一致。7/10 第三轮打击 140 个目标 → 7/11 伊朗封锁海峡并开火 → 7/12 伊朗袭击沙特、科威特、卡塔尔美军基地 → 7/13 美军宣布恢复对伊朗港口全面封锁 + 伊朗导弹击中港口城市科纳拉克 + 胡塞武装袭击沙特机场 + 特朗普威胁摧毁"镐山"地下核设施。
- **核心观察窗口**：7/14 20:00 UTC 美军封锁正式生效后霍尔木兹实际通航量；特朗普 7/16（周五）09:00 ET 全国讲话内容；伊朗是否升级反击（如袭击以色列城市、重启高浓度浓缩）。
- **对消息最敏感资产**：原油、黄金、美元、航空/海运股、军工股。

### 主线 2：美联储政策定价"从加息到不再降息 + 讨论年内加息"

- **方向**：鹰派回潮加速
- **强弱程度**：7/10
- **最近一周一致性**：高度一致。芝商所 FedWatch 7/13 显示 7 月加息概率 ~50%（7/6 时仅 23%）。美联储理事沃勒 7/13 明确表态：核心通胀若再次火热 → 短期内有理由加息；提议将通胀目标改为 1.5-2.5% 区间（"放弃 2% 点目标"）；强调不能重蹈 2021 年覆辙。6 月 FOMC 纪要显示"几位官员认为上月有理由加息"。
- **核心观察窗口**：美国 6 月 CPI（7/14 北京凌晨已公布 vs 市场预期），PPI + Fed 主席沃什国会证词。若核心 CPI ≥0.3%，加息概率将进一步上升。
- **对消息最敏感资产**：收益率曲线（短端 > 长端）、科技/成长股估值、银行股。

### 主线 3：油价暴涨 + 通胀传导重启

- **方向**：上行风险敞口极高
- **强弱程度**：8/10
- **最近一周一致性**：一致上行。WTI 从 $73.52 暴涨至 $78.14（+9.4%），布伦特破 $83。供应端 OPEC 6 月增产 305 kb/d（阿联酋 +164、科威特 +88）部分缓解，但霍尔木兹海峡实际通航量从常态 100+ 艘骤降至 11 艘，结构性供应瓶颈未解。埃尼 CEO 警告：若冲突持续，最迟 2027Q1 油价突破 $80-100 区间上限。
- **核心观察窗口**：EIA/IEA 月报对供需平衡的修正；每周三 EIA 库存数据；每日霍尔木兹海峡船舶追踪数据。
- **对消息最敏感资产**：能源股（利多）、航空/运输（利空）、实际利率/黄金。

### 主线 4：AI / 半导体盈利证伪风险

- **方向**：中性偏空
- **强弱程度**：6/10
- **最近一周一致性**：分歧加大。三星此前 Q2 利润 +18 倍但 STX -6.9%、SK Hynix ADR 上市次日 -9%、美光 -4.3%、闪迪 -12%、英特尔 -6%。高盛研报认为美光业绩将显著超预期（目标价上调至 $900），但市场用脚投票——"AI 算力过剩"担忧 + 存储芯片提前杀估值。台积电 7/16 财报是短期关键锚。
- **核心观察窗口**：7/16 台积电 Q2 财报 + 7/16 Netflix 财报（资本开支指引）。
- **对消息最敏感资产**：SOX、费城半导体指数、纳指相对表现。

### 主线 5：贵金属 / 避险资产 — 流动性挤售 > 传统避险

- **方向**：反常下行（但中期仍利多）
- **强弱程度**：5/10
- **最近一周一致性**：不一致。黄金从 $4,070 跌至 $4,006（-1.6%），跌破 $4,000 心理关口。白银更弱（-$57.96）。反常逻辑：Fed 加息概率骤升 → 美元走强 + 实际利率上行 → 资金抛售一切可变现资产（含黄金）以应对保证金要求，与 2020 年 3 月类似。但央行购金（中国连续 20 个月增持）和地缘尾部风险托底。
- **核心观察窗口**：VIX 若突破 25-30，黄金避险属性将回归；美元指数若突破 103，金价进一步承压。
- **对消息最敏感资产**：黄金矿股、白银、美元。

## 5️⃣ 情景树

### 基准情景（Base Case）— 概率 40%

- **触发条件**：美军封锁后霍尔木兹维持有限通航（日均 20-50 艘而非完全瘫痪）；7/14 美国核心 CPI 环比 +0.25~0.30%（符合预期）；7/16 特朗普全国讲话措辞强硬但无新重大军事升级；WTI 维持在 $75-82 区间；Fed 7 月按兵不动但 9 月加息概率维持 40-50%。
- **权重依据**：最具惯性的"有限冲突 + 通胀温和上行 + 央行观望"路径。OPEC 增产 + 海峡未完全瘫痪 + 美联储仍受 CPI 验证约束。但地缘升级风险已显著上升，从零假设概率 45%（前值）下调至 40%。
- **各资产方向**：
  - 道指 → 震荡偏弱（51,500-53,000）
  - 标普 500 → 区间整理（7,400-7,650）
  - 纳指 → 弱于道指（利率敏感），但半导体有分化行情（25,200-26,200）
  - 美元 → 区间偏强（DXY 101-103）
  - 美债 → 10Y 4.50-4.75%（熊平）
  - 原油 → WTI 75-82 区间
  - 黄金 → 震荡偏弱（3,950-4,150）
- **失效信号**：① 伊朗宣布退出 NPT 或重启 60%+ 浓缩；② 海峡通航降至 0 或美军实质性登陆伊朗；③ 核心 CPI >0.45%

### 牛市情景（Bull Case）— 概率 20%

- **触发条件**：美伊在 7/16 前出现意外停火/外交突破（伊朗外长"公平收费"言论暗示可交易空间）；特朗普全国讲话释放停火信号；海峡通航快速恢复；核心 CPI ≤0.20%；9 月降息概率回归 30%+。
- **权重依据**："以打促谈"框架尚未破裂，双方仍保留交易空间。但烈度远超历史模式，快速降级概率从前值 25% 下调至 20%。
- **各资产方向**：
  - 道指 → 反弹至 53,500+
  - 标普 → 冲击 7,700-7,850
  - 纳指 → 跑赢，SOX 反弹 5-8%（超跌 + 降息预期回归）
  - 美元 → 走弱至 99-100
  - 美债 → 10Y 回落至 4.20-4.40%
  - 原油 → 骤跌至 68-72
  - 黄金 → 中性偏强（4,150-4,300）
- **失效信号**：伊朗袭击以色列城市造成大规模伤亡；美军出现重大伤亡事件；核心 CPI >0.35%

### 熊市情景（Bear Case）— 概率 40%

- **触发条件**：霍尔木兹海峡完全瘫痪（通航趋近于零）；伊朗反击扩大至以色列平民目標或海湾国家关键基础设施遭系统性破坏；核心 CPI ≥0.35% + PPI 超预期；WTI 突破 $90-95；30 年期美债收益率突破 5.25%；Fed 9 月加息概率 >60%；VIX 突破 30+。

- **各资产方向**：
  - 道指 → 急跌至 50,500-51,500
  - 标普 → 急跌 7,200-7,350
  - 纳指 → 受估值压缩冲击最深（24,000-24,800）
  - 美元 → 急升至 104-106
  - 美债 → 收益率全面急升（10Y 4.80-5.00%）
  - 原油 → 暴涨至 $90-100
  - 黄金 → 突破 $4,300-4,500（流动性挤售暂缓，避险再回归）
- **失效信号**：美伊快速达成临时停火协议；伊朗宣布无条件恢复海峡通行；核心 CPI 意外降至 0.12% 以下

## 🔟 凯利仓位校准（风险预算上限，非交易信号）

**核心假设：** 基于情景树，本期唯一可交易的假设是：

> **"美伊冲突有限升级 + CPI 偏热 → 能源股短线做多 + 利率敏感资产（纳指）相对做空"**

但该假设面临以下限制：
- 地缘事件导致止损可能因跳空失效（如周末突发导弹袭击 → 周一油价直接跳空 10%）；
- 交易成本在极端波动期显著扩大；
- 7/16 特朗普讲话是单次不可重复事件，无法事后验证。

### 凯利计算（理论参考）：

| 参数 | 方向 A：做多能源（XLE） | 方向 B：做空纳指（SQQQ/反向） |
|------|------|------|
| 适用前提 | 海峡维持紧张 + CPI 超预期 | 美联储加息概率 >60% + 地缘恶化 |
| 胜率 p | 55% | 50% |
| 败率 q | 45% | 50% |
| 目标收益 G | 8-12%（到 $90-95 WTI） | 5-8%（纳指回调至 24,500） |
| 止损损失 L | 5-8%（WTI 跌回 $72 以下） | 4-6%（纳指反弹回 26,500） |
| 盈亏比 b = G/L | 约 1.5 | 约 1.3 |
| 原始凯利 f\* | (1.5×0.55 - 0.45)/1.5 ≈ **18.3%** | (1.3×0.5 - 0.5)/1.3 ≈ **0%** |

**分数凯利（1/4 Kelly）：**
- 方向 A：约 **4.5%** 账户风险预算
- 方向 B：**0%**（凯利不支持，放弃）

### 实际建议：

**本期不适合使用标准凯利仓位。** 原因：

1. **止损跳空风险**：周末地缘事件可能导致周一开盘直接跳过止损位，实际损失远超 L；
2. **事件单次性**：7/16 特朗普讲话是单次公告，无法用频率统计概率；
3. **情景概率快速重定价**：若伊朗示弱或冲突突然降级，凯利立即转负；
4. **高度相关性**：做多能源与做空纳指在"滞胀"情景下看似对冲，但在"衰退"情景下可能双杀。

**替代方案（风险预算思路）：**
