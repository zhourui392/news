## 5️⃣ 情景树

### 基准情景（Base Case）—— 概率 35%

- **触发条件**：本周末美以对伊朗能源目标的打击"有限"（象征性而非全面）→ 布伦特周一跳空至 $92-95 后回落；8/3 ISM 制造业 PMI ~49（持平）；8/4 AMD 平至略超预期 + SPCX 财报不暴雷但解禁抛售可控（SOX 稳于 10,800-11,300）；8/5 财政部再融资公告维持不变（摩根大通预计）+ LLY/NVO 平至略超预期；8/7 NFP ~15-18 万（稳健但不火爆）；30Y 稳于 5.20-5.30% 区间；加沙停火框架缓慢推进但执行存疑。
- **权重依据**：① ECI 0.9% 超预期但芝加哥 PMI 57.6 强劲 + 密歇根消费者信心 55.2 超预期 = 经济韧性仍在，不至衰退；② AMZN +15% + GOOG +6.7% 确认 AI 锚点，AMD 大概率跟随趋势；③ 摩根大通预计财政部因中期选举暂不调整发行计划；④ 美以对伊朗打击可能"象征性"而非全面升级（特朗普"可以达成协议"）；⑤ VIX 16 显示市场仍有风险偏好。**但概率较 7/30 的 45% 下调 10pct——ECI 超预期 + 30Y 突破 5.275% + 伊朗周末打击风险 = 基准情景的假设条件更加脆弱。**
- **各资产方向**：
  - 道指 -> 区间震荡偏弱（51,500-53,000，能源股受益但利率+地缘压制）
  - 标普 500 -> 区间震荡（7,200-7,600，8/4-8/5 财报密集期决定方向）
  - 纳指 -> 震荡分化（24,000-25,800，AMZN 锚点 vs AAPL 裂痕 + AMD 验证）
  - SOX -> 高位震荡（10,500-11,500，8/4 AMD 是关键验证）
  - 美元 -> 区间偏弱（DXY 99-101，信誉危机持续但 ECI 提供支撑）
  - 美债 -> 10Y 4.65-4.85%，30Y 5.20-5.35%（**5.30% 是失效线**，8/5 再融资公告是关键）
  - 原油 -> WTI 84-92，布伦特 88-96（地缘溢价维持 + OPEC+ 增产预期）
  - 黄金 -> 震荡偏多（4,050-4,250，地缘升级 + 美元弱 + 通胀预期，但 VIX 回落限制上行）
- **失效信号**：① 30Y 突破 5.30%；② 美以全面轰炸伊朗能源设施（布伦特冲 $100+）；③ 8/4 AMD 暴雷（SOX 跌破 10,500）；④ 8/5 财政部再融资公告长端供给超预期；⑤ 8/7 NFP >20 万（加息预期强化）；⑥ 8/6 SPCX 解禁引发科技股连锁抛售；⑦ VIX 重返 22 以上。

### 牛市情景（Bull Case）—— 概率 15%

- **触发条件**：本周末美以**未**轰炸伊朗能源目标（CBS 报道未落地）+ 伊朗封锁海峡声明停留于口头 + 加沙停火框架正式签署；8/3 ISM 制造业 PMI >50；8/4 AMD 超预期 + SPCX 财报稳健（SOX 冲 11,500-12,200）；8/5 财政部再融资公告维持不变 + LLY/NVO 超预期 + 存储财报延续暴涨；8/7 NFP 12-15 万（稳健但不过热）；30Y 回落至 5.10-5.20%；VIX 维持 16 以下。
- **权重依据**：概率较 7/30 的 30% **大幅下调 15pct**，理由：① ECI 0.9% 超预期直接削弱了 Bull 情景的核心条件（薪资通胀降温）；② 30Y 突破 5.275% 逼近 5.30% 失效线；③ 三位美联储官员公开呼吁加息 + 沃什考虑减少会议频率 = 鹰派压力升级；④ CBS 报道美以准备轰炸伊朗能源目标 = 地缘升级而非降级；⑤ AAPL -7.35% + SPCX -3.41% = AI 修复不完整。**Bull 情景需要多个"反向"条件同时成立——美以不打伊朗 + AMD 超预期 + 再融资维持不变 + NFP 适中——联合概率较低。**
- **各资产方向**：
  - 道指 -> 反弹至 52,500-54,000
  - 标普 -> 冲击 7,500-7,800
  - 纳指 -> 25,500-26,500（AMZN 锚点 + AMD 验证 + 存储暴涨延续）
  - 美元 -> 走弱至 98.0-100.0
  - 美债 -> 10Y 回落至 4.50-4.65%，30Y 回落至 5.05-5.20%
  - 原油 -> WTI 80-86，布伦特 85-90（地缘降级 + OPEC+ 增产）
  - 黄金 -> 偏多震荡（4,100-4,300，美元弱 + 地缘尾部对冲）
- **失效信号**：30Y 突破 5.30%；美以轰炸伊朗能源设施；8/4 AMD 暴雷；8/5 再融资公告长端供给超预期；8/7 NFP >20 万；VIX 重返 22。

### 熊市情景（Bear Case）—— 概率 50%

- **触发条件**：本周末美以轰炸伊朗能源设施 → 布伦特周一跳空至 $95-100+；8/3 ISM 制造业 PMI <47（衰退信号）；8/4 AMD 暴雷 + SPCX 暴雷 + 8/6 解禁抛售（SOX 跌破 10,500）；8/5 财政部再融资公告长端供给超预期（30Y 突破 5.30%）+ LLY/NVO 暴雷；8/7 NFP >20 万（加息预期强化至 70%+）；特朗普实施大规模对伊军事打击（布伦特冲 $100+）；加沙停火谈判破裂；30Y 突破 5.30%；VIX 跳空至 25+。

1. **盈亏比极低（0.50）**：止损空间（5-8%）是目标空间（2-4%）的 1.5-2 倍。30Y 5.275% + ECI 偏鹰 + 伊朗打击风险 = 下行空间被严重低估；
2. **胜率仅 35%**：Bear 情景 50% 概率中 AI 大幅下跌，8/4 AMD 暴雷 + 8/6 SPCX 解禁 = 高波动事件密集；
3. **跳空风险使止损失效**：本周末伊朗打击 + 8/4 AMD 财报 + 8/5 再融资公告 = 多重跳空风险源，开盘可能直接跳过止损位。

**假设 B（做多黄金）：凯利微正（1/4 Kelly ≈ 1.4%），可考虑极轻仓配置。** 但需注意：
1. **仅在"本周末美以轰炸伊朗能源设施"确认后才启用**——若未轰炸，黄金可能继续回落至 $4,000-4,050；
2. **风险预算上限约 1.4%**，这是该方向可承受的风险预算上限，不是买入账户 1.4% 的机械指令。名义仓位需按止损距离（约 5%）折算：若止损 5%，则名义仓位约为风险预算 / 止损比例 = 1.4% / 5% ≈ 28% 账户名义价值。但考虑跳空风险和杠杆上限，实际名义仓位应远低于此；
3. **若 30Y 突破 5.30% 或 VIX 突破 25，凯利假设失效**——利率驱动回调可能使黄金先跌后涨，止损可能被跳空击穿。

### 不启用凯利的情况

- **本周末（8/1-8/2）**：CBS 报道美以可能轰炸伊朗能源目标——地缘不可控，所有仓位假设失效；
- **8/4 AMD/SPCX 财报公布前 2 小时**（盘后）：单次事件无法用频率统计概率；

- **30Y 美债收益率突破 5.30%**：长端收益率失控，所有估值假设失效；
- **VIX 重返 22 以上**：恐慌加速器重启，所有趋势假设失效；
- **美以冲突全面升级（霍尔木兹实质封锁/美军大规模轰炸伊朗）**：油价飙升、避险暴涨，美股全面承压；
- **布伦特单日波动 >6%**：能源仓位止损距离失效；
- **USD/JPY 跌破 155 或突破 162**：极端汇率波动信号，套息交易平仓连锁风险；
- **加沙停火谈判破裂 + 哈马斯拒绝解除武装**：中东地缘重新升级。

### 凯利校准的失效条件
