## 为什么会有影响（因果链）

### 1. 外盘溢出链：PCE 转负 + 美股暴涨 + SOX +8.19% -> A 股超跌反弹

这是 7/31 A 股开盘的**第一推升力**。传导路径：6 月 PCE 环比 -0.1%（2020 年来首次转负）-> 9 月加息预期降温 -> 30Y 美债收益率回落预期 -> 全球长久期资产折现率下降 -> 美股全线暴涨（纳指 +2.78%、SOX +8.19%）-> VIX 暴跌 17% -> 全球风险偏好大幅修复 -> A 股 7/31 大概率高开跟随。**这是 7/30"三重利空"的彻底反转**：7/30 的 FOMC 鹰式暂停 + 30Y 破 5.24% + Meta 暴雷导致 A 股 CPO/存储/光刻机连环杀跌，7/31 PCE 转负 + SOX +8.19% + VIX 熄火使这些利空被显著削弱。**A 股的超跌反弹力度**取决于高开后获利盘与抄底资金的博弈--7/30 中际旭创 597 亿历史天量成交意味着大量筹码在低位换手，反弹空间存在但路径可能曲折。

### 2. 半导体趋稳链：KOSPI +16% + SK 海力士 +26% + 苹果评估长鑫芯片 -> A 股存储/算力链反弹

传导路径：SK 集团会长直接买入 + 韩国 20 万亿韩元 AI 投资计划 + 三星/SK 海力士利润超预期 -> KOSPI 创纪录反弹（+16%）-> 全球半导体去杠杆趋稳 -> A 股半导体情绪修复 -> CPO/存储/光刻机超跌反弹。**关键催化**：苹果 CEO 库克回应正在评估长鑫科技芯片 -> 国产存储进入苹果供应链预期升温 -> 长鑫科技及相关概念股（兆易创新/江波龙/佰维存储）催化。**基本面底仍在**：1-6 月集成电路利润 +2579.5%、三星芯片利润 +250 倍、SK 海力士利润创纪录、HBM4 扩产、长江存储专利辟谣、中际旭创/兆易创新回购。7/30 恐慌性出清（科创 50 -5.38%）在全球半导体趋稳下具备超跌反弹条件。

### 3. 政策预期链：政治局会议"增量政策" + 降准降息预期 -> 政策底延续

传导路径：政治局会议"及时谋划出台务实管用的增量政策" + "深化资本市场投融资综合改革" -> 政策底信号明确 -> 降准降息预期升温（董希淼：三季度有望降准降息）-> 利率敏感型板块（地产/券商/银行）受益 + 流动性环境改善 -> ETF 托底加码 -> A 股下方支撑明确。7/30 午后深 V 修复（创业板从 -6.5% 收窄至 -3.97%）即为政策底 + ETF 托底的验证。**政策催化窗口**：10 月二十届五中全会前，"增量政策"预期可能反复提供主题性机会。"人工智能+"行动直接利好 AI/算力/半导体板块。

### 4. 资金面链：融资余额三日 -919 亿极端 + ETF 托底 + 杠杆回流预期

传导路径：融资余额连续三日大幅减少（-919 亿）-> 杠杆资金去化接近极端 -> 历史经验：连续三日大幅减少后往往出现超跌反弹 -> 在 PCE 转负 + KOSPI 暴涨外部利好下，杠杆资金有望快速回流 -> 推动超跌板块反弹。同时 ETF 资金（7 月 4100 亿）+ 央行连续净投放 = 下方支撑明确。**关键博弈**：若 7/31 高开后杠杆资金回流 + ETF 不退出 -> 反弹延续至 3450+；若高开后获利盘出逃 + ETF 获利了结 -> 反弹可能昙花一现，回落至 3300 附近。

### 5. 汇率与中美利差链：PCE 转负 -> 美元偏弱 + 人民币偏强 -> 北向资金回流预期

传导路径：PCE 转负 -> 9 月加息预期降温 -> 美元偏弱（DXY 100.14）+ 日韩联手干预猜测 -> 人民币偏强（USDCNH 6.7408，中间价 6.7892 创 2023 年 2 月以来最高）-> 中美利差走阔压力缓解 -> 北向资金回流预期 -> 蓝筹/消费受益。**日韩联手干预的特殊影响**：日本最高外汇事务官员三村淳"获得美方超出精神层面的支持" + 韩国副财政部长"与美日密切协调" -> 日韩联手干预猜测升温 -> 全球套息资金节奏可能被打乱 -> 美元容忍区间收窄 -> 新兴市场资金回流。

### 6. 地缘缓和链：哈马斯协议 + 美军"已完成" + 油价回落 -> 避险情绪消退

传导路径：哈马斯称与以色列达成协议 + 美军宣布"已完成大规模打击" + 卡塔尔恢复经霍尔木兹运输 LNG -> 地缘风险溢价消退 -> 油价回落（SC 原油 -2%）-> 通胀预期下行 -> 30Y 美债收益率回落预期 -> 全球估值锚修复 -> A 股高估值成长股受益。同时，油价回落 -> A 股能源股支撑减弱但对中下游（航空/化工/物流）偏多。**但尾部风险仍存**：哈马斯协议执行面临阻力（"以色列担心哈马斯耍花招，伊朗在背后拖后腿"）、伊朗革命卫队强硬表态、特朗普寻求对伊加征关税授权。
