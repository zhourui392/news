## 3️⃣ 当前主线综合判断

### 主线 1：美联储与美元 —「鹰派回潮 + 纪要前夕，美元拥挤多头」

- **方向**：轻度利空（对美股估值构成压力）
- **强弱程度**：中强
- **最近一周一致性**：高度一致。CFTC 美元净多头升至 2015 年以来最高（近 400 亿美元）+ 30 年期美债重返 5% + 10 年期升至 4.53% + 沃勒鹰派言论（"不会为财政赤字融资维持低利率"）。Julius Baer 的"美联储不太可能加息"属少数派观点，未改变主流定价。
- **对哪类消息最敏感**：今晚 20:00 UTC FOMC 纪要。若出现"多数委员认为年内仍需进一步行动"措辞，美元和美债收益率将急升，纳指估值压缩。

### 主线 2：中东地缘 / 油价 —「和平红利定价被单日暴涨打破」

- **方向**：从"中性偏利"**修正为"高度不确定"**
- **强弱程度**：强（边际变化极大）
- **最近一周一致性**：**不一致**。此前一周 WTI 从 68.55 跌至 66-68 区间，市场定价和平红利。但 7/8 WTI 单日暴涨 5.3% 至 72.18，触发因素包括：美国恢复对伊朗石油制裁 + 伊朗誓言"毁灭性回应" + 沙特油轮在霍尔木兹附近受损 + 伊朗首席谈判代表称美国"严重违反"备忘录。
- **对哪类消息最敏感**：7/11 巴基斯坦和谈节点、任何新的油轮/航道事件、伊朗核设施重启信号。

### 主线 3：AI / 半导体盈利 —「盈利验证期 + 获利回吐」

- **方向**：利多但边际减弱
- **强弱程度**：中强（从"强"下调）

- **对哪类消息最敏感**：SK Hynix 定价反馈、费城半导体板块开盘强度、博通/苹果合作后续。

### 主线 4：银行 / 财政 / 政策 —「中性偏结构」

- **强弱程度**：中

- **对哪类消息最敏感**：关税/贸易法案进展、美债拍卖需求、德法财政信号。

### 主线 5：贵金属 / 避险 —「美元走强压制，但央行购金托底」

## 5️⃣ 情景树

### 基准情景（Base Case）— 概率 45%

- **触发条件**：FOMC 纪要偏中性（承认通胀下行但未排除进一步行动）；7/13 核心 CPI +0.25%；美伊 7/11 谈判维持"框架 + 继续接触"但无突破性制裁豁免；WTI 回落至 68-72 区间。
- **权重依据**：最具惯性的路径——市场已部分定价加息风险但未恐慌，经济软着陆叙事仍在，AI 盈利季风尚不能判断见顶。但 WTI 单日暴涨后，地缘尾部风险上升，基准概率从 50% 下调至 45%。
- **各资产方向**：
  - 道指 → 震荡偏多（52,000-54,000）
  - 标普 500 → 小幅上行（7,450-7,650）
  - 纳指 → 跑赢其他（25,500-26,800），半导体继续领涨但波动加大
  - 美元 → DXY 100-102 区间震荡
  - 美债 → 10 年期 4.40-4.70% 区间
  - 原油 → WTI 68-72 区间（从 65-70 上修）
  - 黄金 → 震荡偏弱（4,050-4,250）
- **失效信号**：CPI >0.4% + 纪要鹰派；或美伊谈判正式破裂 + 霍尔木兹再封锁；或 30 年期美债突破 5.25%。

### 牛市情景（Bull Case）— 概率 25%

- **触发条件**：FOMC 纪要确认委员会主流认为"当前利率具限制性，无需进一步行动"；7/13 核心 CPI 月率 ≤+0.15%；7/11 美伊公开可验证的制裁解除备忘录；SK Hynix 定价后首日大幅跑赢。
- **权重依据**：通胀回落速度 + 央行转向迹象 + 地缘缓和三重顺风同时具备时才能驱动。
- **各资产方向**：
  - 道指 → 上攻 55,000+
  - 标普 → 冲击 7,800-8,000
  - 纳指 → 加速上扬至 27,500+
  - 美元 → 走弱至 98-99
  - 美债 → 10 年回落至 4.00-4.20%
  - 原油 → 回落至 62-66（和平红利）
  - 黄金 → 中性（4,150-4,300）
- **失效信号**：核心 CPI 超预期 / 突发的重大地缘升级事件（如伊朗重启 60%+ 铀浓缩）。

### 熊市情景（Bear Case）— 概率 30%

- **触发条件**：FOMC 纪要中出现多数委员支持"年内仍需加息 1 次"措辞；7/13 核心 CPI >0.35%；美伊谈判破裂伴随伊朗重启 20%+ 浓缩；WTI 突破 78 美元触发通胀预期回升；30 年期美债突破 5.25%。
- **权重依据**：WTI 单日暴涨 5.3% 已证明地缘尾部风险定价不足；通胀粘性 + 政策滞后效应 + 季节性因素（Q3 通常是风险资产高波动期）。熊市概率从 25% 上调至 30%。
- **各资产方向**：
  - 道指 → 回调至 50,000-51,000
  - 标普 → 急跌 7,200-7,350
  - 纳指 → 受估值压缩冲击最大，24,000-24,800
  - 美元 → 急升至 103-105
  - 美债 → 收益率全面急升（10 年突破 4.80%）
  - 原油 → 暴涨至 78-85（航道风险重燃）
  - 黄金 → 突破 4,300-4,400
- **失效信号**：7/13 CPI 意外降至 +0.12% 以下 / 美联储某委员提前发出"数据依赖 + 暂缓加息"信号 / 霍尔木兹全面通航 + 伊朗宣布自愿暂停核计划。
