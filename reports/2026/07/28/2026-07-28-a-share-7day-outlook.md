**关键事实**：

- 7/28 亚太开盘：韩国 KOSPI -8%（SK 海力士 -11%、三星 -9%，触发侧车机制）、日经 -4%、台湾加权 -3.36%、铠侠 -18%。

**对 A 股传导**：7/27 长鑫科技上市创纪录（+465%、成交破千亿）曾带动科创 50 V 型反转，但隔夜全球半导体恐慌意味着 7/28 A 股半导体板块难以独善其身。华虹宏力（7/27 已跌 10%）、兆易创新（7/27 触及跌停）等非龙头可能进一步承压。长鑫科技本身作为新上市个股，换手率超 66% 后面临获利了结压力。**但 A 股半导体有其独立性**：①长鑫上市的国产替代叙事不随美股波动消失；②1-6 月电子行业利润 +96.9% 的基本面底确认；③中信证券"坚定看好超跌后的电子板块投资机会"研报发布。预计 7/28 半导体开盘跌幅 2-5%，但能否盘中回升取决于全球半导体恐慌是否企稳。

### 二、FOMC 二元事件逼近：市场进入极端观望模式

**定性**：中性偏空（不确定性溢价上升，波动率必然加剧）。

**关键事实**：
- FOMC 7/28-7/29 议息，北京时间 7/30 凌晨 02:00 公布利率决议 + 沃什新闻发布会。
- CME"美联储观察"：7 月维持不变概率 63.7%，加息 25bp 概率 36.3%。9 月维持不变仅 18.5%，加息 25bp 概率 55.7%。
- 城堡证券预计本周可能意外加息 25bp，称将"果断终结前瞻指引时代"，"市场可能低估了沃什的鹰派程度"。
- 花旗坚持押注按兵不动，汇丰认为除非加息否则美元不太可能大涨，凯投宏观预计美联储 2027 年可能与欧央行/英央行政策分化。
- 特朗普密集喊话"利率应该更低""美国应拥有全球最低的利率"，与市场加息预期形成张力。
- 7/29 同日公布 6 月核心 PCE + Q2 GDP 初值，是本周最大数据-政策双重事件。

**对 A 股传导**：FOMC 是本周 A 股最大外部变量。若偏鸽（强调"能源是暂时性冲击"、不讨论加息）-> 美债收益率回落 -> 中美利差收窄 -> 北向回流 -> A 股反弹；若偏鹰（城堡证券预言兑现、加息 25bp 或明确暗示 9 月加息）-> 美债收益率跳升 -> 利差走阔 -> 北向加速流出 -> A 股承压。**7/28（周二）为 FOMC 前最后一个完整交易日，市场将进入极端观望模式**，预计成交可能缩量，高波动个股（科创板/创业板）宜减仓避险。

### 三、油价崩塌持续 + 地缘脆弱：通胀利好与尾部风险并存

**定性**：利多（通胀/成本端）但伴尾部风险。

**关键事实**：
- WTI $82.61（-7.50%）、布伦特 $88.36（-8.70%），SC 原油 7/28 早盘再跌近 5%。美国 SPR 降至 1983 年以来最低（3.077 亿桶）。
- 停火脆弱：特朗普"窗口有限，若破裂将重启军事行动"；伊朗拒绝美方 2 项极端要求；胡塞袭击沙特吉赞炼油厂（储油罐起火）；红海航运量降至数月低位；霍尔木兹海峡仍关闭，美军迫使 17 艘商船改道。
- 美国官员认为"经济制裁对伊朗杀伤力远超轰炸"，暗示长期制裁路线可能取代短期军事行动。
- 巴克莱警告：若当前局势再持续 1-3 个月，油价存在每桶上涨 2-10 美元的风险。
- 模型预判美伊冲突缓和窗口 7/22-7/30，目前停火兑现。距中期选举不足百日，白宫有强烈动机降温局势。

**对 A 股传导**：油价回落对 A 股中下游（航空、化工下游、物流）**偏多**；对能源股（中国石油、中国石化、中国神华）及能化期货**偏空**。油价回落 -> 全球通胀预期下行 -> 美债收益率回落 -> 北向资金压力减轻。但霍尔木兹仍关闭 + 胡塞持续袭击 = 地缘尾部风险未消除，若停火破裂油价可能急速反弹。

## 为什么会有影响（因果链）

### 1. 外盘溢出链：美股半导体暴跌 -> 亚太恐慌 -> A 股开盘承压

这是 7/28 A 股开盘的**第一压制力**。传导路径：英伟达 7500 亿 AI 担保引发 CDS 创史上最大涨幅 -> 市场质疑"借钱给客户买芯片"系统性风险 -> 美股 SOX -5%、英伟达 -5%、SK 海力士 ADR 跌破发行价 -> 7/28 亚太开盘：KOSPI -8%（SK 海力士 -11%、三星 -9%）、日经 -4%、台湾加权 -3.36% -> 全球半导体恐慌蔓延 -> A 股半导体/科创板开盘大幅低开。**关键传导节点**：A 股半导体能否独立于全球恐慌？7/27 长鑫上市 + 电子行业利润 +96.9% + 国产替代叙事提供了基本面支撑，但短期情绪冲击难以避免。若 KOSPI 跌幅继续扩大或日经跌破 62000，A 股跌幅可能加深。

### 2. FOMC 二元事件链：加息悬念 -> 观望情绪 -> 高波动个股减仓

传导路径：城堡证券预计可能意外加息 25bp + CME 加息概率 36.3% + 沃什"政策黑盒" -> 市场不确定性溢价上升 -> FOMC 前资金避险（减仓高波动个股）-> 7/28 为 FOMC 前最后一个完整交易日 -> 成交可能缩量 + 创业板/科创板承压。**这条链的关键**：若 FOMC 偏鸽（维持不变 + 措辞温和），7/30 A 股可能反弹收回跌幅；若偏鹰（加息或明确暗示 9 月加息），A 股可能加速下行。二元事件前的最优策略是降低仓位而非押方向。

### 3. 油价/地缘链：停火维持 + 油价崩塌 -> 通胀利好持续但尾部风险未消

传导路径：美伊停火维持 -> WTI -7.5%、布伦特 -8.7%、SC -5% -> 全球通胀预期下行 -> 美债收益率回落（但降幅有限，因 FOMC 不确定性压制）-> 中美利差边际收窄 -> 北向资金流出压力减轻（但被 FOMC 避险抵消）。同时，油价回落 -> A 股中下游成本改善（航空、化工下游、物流利好）-> 能源股承压。**尾部风险**：霍尔木兹仍关闭 + 胡塞袭击沙特 + 伊朗拒绝美方极端要求 -> 若停火破裂，油价可能急速反弹至 $95+，传导链逆转。

### 4. 汇率与中美利差链：美元微涨 + FOMC 避险 -> 人民币偏弱

传导路径：DXY 微涨 0.07% + FOMC 加息预期 + 亚太避险需求美元 -> USDCNH 偏弱 -> 北向资金流出压力上升。但停火 + 油价回落限制了美元上行空间。**关键分叉**：7/29 FOMC + PCE。若 PCE 低于预期 + FOMC 偏鸽 -> 美元走弱 -> 人民币升值 -> 北向回流；若 PCE 超预期 + FOMC 偏鹰 -> 美元走强 -> USDCNH 贬至 6.82+ -> 北向加速流出。7/28 人民币中间价是重要观察窗口。

### 5. 产业景气链：全球半导体恐慌 vs A 股国产替代独立逻辑

这是 7/28 最核心的**博弈点**。全球半导体恐慌（英伟达 CDS + SK 海力士破发 + SOX -5%）传导至 A 股，但 A 股半导体有独立逻辑：①长鑫科技上市（国产存储龙头，市值 3.28 万亿）确立了国产替代叙事；②1-6 月电子行业利润 +96.9%、集成电路制造利润 +2579.5% 的基本面底；③国资委"AI+"专项行动 + 阿里云适配 Kimi K3 的政策/产业催化；④中信证券"坚定看好超跌后的电子板块"。**博弈结果**：7/28 半导体板块大概率低开 2-5%，但盘中能否回升取决于全球恐慌是否企稳 + 长鑫能否守住涨幅。若长鑫大幅回调（换手率超 66% 后获利了结压力大），科创板可能跌破 1750。

### 6. 情绪与估值链：7/27 反弹成果 vs 7/28 恐慌回吐

7/27 放量普涨（2.08 万亿、近 5200 只上涨）+ 融资余额回升 100 亿确认了情绪底。但 7/28 亚太暴跌（KOSPI -8%、日经 -4%）将测试这一情绪底的韧性。若 A 股开盘跌幅控制在 1-2% 以内且午后企稳，则 7/27 的反弹成果部分保留，情绪底确认；若跌幅扩大至 3%+ 且放量下跌，则 7/27 反弹可能被定义为"熊市反弹"而非趋势反转。**关键观察**：两市成交额是否维持 1.8 万亿以上（维持则承接力仍在）、融资余额是否继续回流。
