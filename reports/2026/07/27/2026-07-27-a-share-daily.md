**定性**：利多（情绪与产业景气），但伴随结构性虹吸副作用（中性偏空非龙头半导体）。

**关键事实**：长鑫科技（国产存储芯片龙头）7/27 登陆科创板，发行价 8.66 元，收涨 465.82%，盘中一度涨超 530%，总市值 3.28 万亿元**超越工商银行成为 A 股总市值"一哥"**，盘中市值一度达 3.61 万亿**超过美股英特尔**。全天成交额超 1400 亿元，**创下 A 股单日个股成交额历史纪录**（超越东方财富 2024/10/9 的 900.38 亿），换手率超 66%。上市首小时即破千亿成交，因交易量过大一度出现交易卡顿。与此同时，科创 50 盘初一度跌超 3%（华虹宏力 -10%、兆易创新触及跌停），反映长鑫对板块内其他半导体个股的**资金虹吸效应**显著。

## 为什么会有影响（因果链）

### 1. 外盘溢出链：停火 → 油价崩塌 → 风险偏好回升 → A 股普涨

这是今日 A 股反弹的**第一推力**。传导路径：美伊暂停互袭（13 天空袭叫停）→ WTI -6.7%、布伦特 -6.45%、SC 原油 -8% → 全球通胀预期下行 → 美债收益率回落（10Y 从 4.68% 区间）→ 中美利差边际收窄 → 人民币升值（中间价 6.7911）→ 北向资金流出压力减轻 → A 股成长股估值锚改善。同时，纳指期货 +1.4%、日韩股市高开 → 全球风险偏好共振 → A 股跟随高开。**这条链今日完全兑现**，盘前展望对此判断准确。但持续性取决于停火能否维持 + 7/29 FOMC 结果——停火是"战术性暂停"（伊朗"怀疑多于乐观"、胡塞仍袭击沙特），若 FOMC 偏鹰则油价回落带来的利率预期改善会被部分收回。

### 2. 产业景气链：长鑫上市 + 工业利润 +96.9% → AI capex 叙事强化 → 成长风格占优

今日创业板 +3.16% 领涨的核心驱动力。传导路径：长鑫科技上市创纪录（市值 3.28 万亿成 A 股"一哥"、成交破千亿创历史）+ 国家统计局确认电子行业利润 +96.9%（算力需求驱动）→ AI capex supercycle 叙事获"市场表现 + 官方数据"双重背书 → 成长风格（创业板/科创 50）跑赢蓝筹（上证/沪深 300）→ PCB/电力/创新药等题材扩散轮动 → 市场广度改善（近 5200 只上涨）。**但副作用是资金虹吸**：长鑫单日吸金超 1400 亿，导致华虹宏力 -10%、兆易创新触及跌停——这是"龙头上市挤压非龙头"的结构性效应，盘前未充分预料。这条链的中期持续性取决于英伟达 2500 亿担保 OpenAI 数据中心项目落地 + 本周美股科技财报（MSFT/META 7/30、AAPL/AMZN 7/31）验证 AI capex 指引。

### 3. 政策预期链：央行净回笼 vs 风险偏好 → 流动性信号被市场忽略

今日**唯一与盘前预期不符的利空**。传导路径：4000 亿 MLF + 3985 亿逆回购到期 → 央行仅做 3255 亿 7 天逆回购 → 净回笼 4730 亿 → 银行间流动性边际收紧 → 正常情况下应压制短端利率上行 + 风险偏好。但今日市场**完全忽略了这一利空**——两市放量至 2.08 万亿、长鑫吸金 1400 亿、近 5200 只上涨，说明风险偏好回升的力量远超流动性收紧的压制。可能的原因：①银行间流动性仍充裕（净回笼是"收短放长"结构性调整而非全面收紧）；②长鑫上市带来的打新资金回流 + ETF 放量弥补了央行回笼；③市场更关注外部环境改善而非国内流动性。**但这条链是潜在风险**——若本周 FOMC 偏鹰 + 央行持续净回笼，流动性收紧效应可能滞后显现。

### 4. 油价/地缘链：停火 → 油价回落 → 能源股承压 vs 中下游受益

油价崩塌对 A 股是双刃剑，今日**利空面（能源化工）与利多面（中下游 + 风险偏好）同时兑现**。利空：SC 原油 -8%、燃油 -8%、纯苯 -7%，A 股能源股（中国石油、中国石化、中国神华）及能化期货全线承压。利多：航空（燃油成本下降）、化工下游（原料成本降低）受益，且油价回落 → 通胀预期下行 → 美债收益率回落 → 北向资金压力减轻 → A 股估值锚改善。**净效应今日偏多**（风险偏好回升主导），但若停火破裂（特朗普称"若不能 100% 达成目标绝对会恢复全面战争"）+ 布伦特反弹回 92+，则利空面将重新主导。

### 5. 汇率与中美利差链：美元走弱 → 人民币升值 → 北向压力减轻

传导路径：停火 + 油价崩塌 → 避险美元走弱（DXY 回落）→ 人民币中间价升值 28 点至 6.7911 → 中美利差边际收窄 → 北向资金流出压力减轻 → A 股成长股（北向重仓的消费/科技）获支撑。**关键分叉点**：7/29 FOMC + PCE。若 PCE 低于预期 + FOMC 偏鸽 → 这条链延续 → 北向回流；若 PCE 超预期 + FOMC 偏鹰 → 链逆转 → USDCNH 贬至 6.80+ → 北向加速流出。今日人民币偏强是对盘前"USDCNH 偏强震荡 6.74-6.78"判断的验证。

### 6. 情绪与估值链：放量 + 普涨 + 多主线轮动 → 风险偏好回暖确认

两市成交 2.08 万亿（放量 1455 亿）+ 近 5200 只上涨 + 超百股涨停 + PCB/电力/创新药/军工/固态电池多主线轮动 → 市场广度显著改善 → 风险偏好从"极端低位"回升。这与盘前中信证券"负面叙事已反映到极端跌幅中、8 月修复概率很高"的判断一致。情绪回暖的持续性仍取决于本周 FOMC + 财报，但今日的放量普涨至少确认了"政策底 + 情绪底"的共振——央行净回笼都未能压制市场，说明内生承接力在增强。
