### 1. 政策底 vs 市场底的博弈链（已部分验证）
7/17 暴跌（上证 -3.05%）→ 政策端密集响应（证监会座谈会 + 央国企回购增持 + 央行净投放 + 灵均自购）→ 7/20 A 股 V 型反弹（沪深 300 +1.53%）→ **政策底单日被市场定价**。但融资余额 7/20 再降 596.85 亿（两日累计 -1396 亿）→ 杠杆出清未完成 → 市场底通常滞后政策底 1-2 周 → 且需地缘/油价/加息预期至少一项边际改善 → 若特朗普不扩大战事 + 油价回落 + 7/22-23 财报超预期 → 市场底确认；若特朗普扩大战事 + 油价突破 WTI 95 → 政策底被地缘顶压制，二次探底。

### 2. 特朗普"数日内决策"的地缘拐点链
福克斯 7/21 独家"特朗普数日内决定是否扩大对伊战事" → 若扩大（规模"远超"九晚空袭）→ 油价突破 WTI 90-95 → 通胀预期回升 → 9 月加息概率升至 60%+ → 美元突破 101.5 → 人民币测试 6.85 → 北向资金外流 → A 股成长股估值承压。若不扩大 + 外交突破（伊朗代表团访伊斯兰堡 / 伊拉克总理访德黑兰）→ 油价回落至 WTI 80 以下 → 加息预期退潮 → 美元走弱 → 人民币升值 → 北向资金回流 → A 股超跌反弹。这是未来 7 天最大的分叉点。

### 3. 半导体"基本面强 vs 情绪面崩"的矛盾链
A 股半导体业绩预告大幅预增（星宸 +584%、富创 +877%）+ 工信部数据（集成电路出口 +88.7%、智能算力 +177%）+ 韩国 7 月前 20 天芯片出口 +180% → 基本面强劲确认 → 但 KOSPI -4.72% 侧车 + SK 海力士/三星 -4.4% + 花旗下调韩股 + 铠侠腰斩 → 亚太杠杆去杠杆链未终结 → A 股半导体 7/20 反弹力度弱（创业板 +0.42% vs 沪深 300 +1.53%）→ 超跌反弹需等待 7/22 Alphabet/特斯拉 + 7/23 英特尔财报验证 + KOSPI 企稳。

### 4. 油价传导的化工成本压力链
WTI 85 / 布伦特 90+ → 7/21 早盘化工期货普跌（PTA/低硫燃料油/焦炭跌超 2%）→ 化工/航空/运输成本端承压 → A 股化工股偏空。同时油价高位 → 通胀预期回升 → 9 月加息概率 53.5% → 美元走强 → 中美利差倒挂扩大 → 北向资金回流受阻 → 成长股估值承压。这是地缘冲突向 A 股传导的核心负反馈链。

### 5. 人民币持稳 + 港股反弹的结构性支撑链
人民币中间价 6.7948（温和贬值 14 点但持稳）→ 贸易顺差 + 中间价管理 + 资本管制缓冲 → A 股底部支撑。港股 7/20 反弹（恒指 +2%+、恒生科技 +3%+）→ 外资并非全面撤离 → 但智谱 -13%/MINIMAX -10% → AI 估值选择性再审视 → 外资在"红利/金融"与"AI 科网"之间再平衡 → A 股内部风格极致分化延续（沪深 300 +1.53% vs 深证 -0.71%）。

### 6. 工信部产业政策的结构性行情锚链
工信部 7/20 数据（工业增加值 +5.4%、高技术制造业 +13.3%、集成电路出口 +88.7%、智能算力 +177%、人形机器人 400+ 款、创新药 38 款）→ 硬科技/创新药/机器人/算力中期景气确认 → 为结构性行情提供基本面锚 → 但短期催化被地缘 + 加息预期对冲 → "利好被利空淹没"风险高 → 若地缘缓和，产业政策主线可能主导结构性行情。
