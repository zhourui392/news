## 5️⃣ 情景树

### 基准情景（Base Case）-- 概率 45%

- **触发条件**：美伊谈判维持"薛定谔状态"（既不全面破裂也不实质突破），霍尔木兹海峡部分恢复通航但不完全开放；8/4 AMD 平至略超预期 + SPCX 财报不暴雷但解禁抛售可控（SOX 稳于 11,200-11,800）；8/5 财政部再融资公告维持"不增加 note/bond 发行"指引 + ISM 服务业 PMI ~54 + LLY/NVO 平至略超预期 + ADP ~7-10 万；8/6 初请 ~20 万 + SPCX 解禁抛售可控；8/7 NFP 8-15 万（稳健但不火爆）+ 失业率 4.2% 持平；30Y 稳于 5.15-5.30%；油价 WTI 维持 $77-82。
- **权重依据**：① 8/3 道指创收盘新高 + 纳指 +2.13% + 油价暴跌 = 风险偏好修复强劲；② AMZN/MSFT/GOOG 三锚点确认 AI 叙事 + PLTR/SNAP 超预期 = 财报季整体向好；③ 油价暴跌缓解通胀预期 -> 30Y 回落至 5.23%；④ 八次"威胁-撤回"循环 = 市场已形成条件反射式定价，薛定谔状态是常态；⑤ 多数交易商预计财政部"不增加 note/bond 发行"。**概率较 7/31 的 35% 上调 10pct--美以未轰炸伊朗 + 油价暴跌 + AI 三锚点 = 基准情景条件改善。**
- **各资产方向**：
  - 道指 -> 高位震荡偏多（52,500-54,000，道指创新高后有惯性）
  - 标普 500 -> 震荡偏多（7,450-7,700，距历史新高约 20 点，财报季验证）
  - 纳指 -> 震荡偏多分化（25,000-26,500，AI 三锚点 vs AMD/SPCX 验证）
  - SOX -> 高位震荡（11,000-11,800，8/4 AMD 是关键验证）
  - 美元 -> 区间偏弱（DXY 99-101，干预 + 信誉危机 vs 加息预期）
  - 美债 -> 10Y 4.60-4.80%，30Y 5.15-5.30%（**5.30% 是失效线**，8/5 再融资公告是关键）
  - 原油 -> WTI 77-82，布伦特 82-87（地缘溢价部分回落 + OPEC+ 增产预期，但海峡未完全恢复）
  - 黄金 -> 震荡（4,050-4,200，地缘不确定性 + 美元弱支撑，但 VIX 低位 + 加息预期压制）
- **失效信号**：① 30Y 突破 5.30%；② 美以全面轰炸伊朗能源设施（布伦特冲 $95+）；③ 8/4 AMD 暴雷（SOX 跌破 11,000）；④ 8/5 财政部再融资公告长端供给超预期；⑤ 8/7 NFP >15 万且失业率下降（加息预期强化至 80%+）；⑥ 8/6 SPCX 解禁引发科技股连锁抛售；⑦ VIX 重返 22 以上；⑧ 美伊谈判全面破裂 + 伊朗报复性军事行动。

### 牛市情景（Bull Case）-- 概率 25%

- **触发条件**：美伊谈判出现实质突破（霍尔木兹海峡正式重开 + 停火确认）-> 油价续跌至 WTI $72-76；8/4 AMD 超预期 + SPCX 财报稳健（SOX 冲 11,800-12,500）；8/5 财政部再融资公告维持不变 + ISM 服务业 PMI >54 + LLY/NVO 超预期 + SNDK/WDC 延续暴涨 + ADP <8 万（劳动力市场降温）；8/6 初请 >21 万（劳动力市场降温）+ SPCX 解禁抛售可控；8/7 NFP <8 万 + 失业率升至 4.3%（加息预期降温）；30Y 回落至 5.05-5.20%；VIX 维持 16 以下。
- **权重依据**：概率较 7/31 的 15% **上调 10pct**，理由：① 8/3 道指创收盘新高 + 纳指 +2.13% = 风险偏好修复强劲；② 油价暴跌 5-7% + 30Y 回落至 5.23% = 通胀/加息压力缓解；③ AMZN/MSFT/GOOG 三锚点 + PLTR/SNAP 超预期 = AI 叙事 + 财报季向好；④ 美以未轰炸伊朗 = Bear 尾部风险未兑现；⑤ ISM 制造业 55.6 = 经济韧性（不衰退）。**但概率未高于 25% 因：伊朗明确否认谈判 + 拒绝海峡提议 + 雷扎伊强硬 = 地缘随时反转；9 月加息 73.6% + 8/5 再融资公告 = 利率压力未消；SPCX 8/6 解禁 = 科技股尾部风险。**
- **各资产方向**：
  - 道指 -> 反弹至 53,500-55,000
  - 标普 -> 冲击历史新高 7,620-7,800
  - 纳指 -> 26,000-27,000（AI 三锚点 + AMD 验证 + 存储暴涨）
  - 美元 -> 走弱至 98.0-100.0
  - 美债 -> 10Y 回落至 4.45-4.65%，30Y 回落至 5.05-5.20%
  - 原油 -> WTI 72-76，布伦特 78-82（地缘降级 + OPEC+ 增产）
  - 黄金 -> 偏多震荡（4,100-4,300，美元弱 + 地缘尾部对冲，但油价下跌限制通胀驱动）
- **失效信号**：30Y 突破 5.30%；美以轰炸伊朗能源设施；8/4 AMD 暴雷；8/5 再融资公告长端供给超预期；8/7 NFP >15 万；VIX 重返 22；美伊谈判全面破裂。

### 熊市情景（Bear Case）-- 概率 30%

- **触发条件**：美伊谈判全面破裂 + 伊朗报复性军事行动（封锁海峡/袭击美军/袭击沙特）-> 布伦特跳空至 $90-95+；8/4 AMD 暴雷 + SPCX 暴雷 + 8/6 解禁抛售（SOX 跌破 11,000）；8/5 财政部再融资公告长端供给超预期（30Y 突破 5.30%）+ ISM 服务业 PMI >55（加息理由强化）；8/7 NFP >15 万且失业率下降（加息预期强化至 80%+）；特朗普实施大规模对伊军事打击（布伦特冲 $95+）；30Y 突破 5.30%；VIX 跳空至 22+。
- **权重依据**：概率较 7/31 的 50% **下调 20pct**，理由：① 7/31 CBS 报道美以准备轰炸伊朗能源目标**未兑现**（Bear 核心催化剂未触发）；② 油价暴跌 5-7%（WTI $79.94）= 地缘溢价大幅回落；③ 8/3 道指创收盘新高 + 纳指 +2.13% = 风险偏好修复；④ AMZN/MSFT/GOOG 三锚点 + PLTR/SNAP 超预期 = AI 叙事修复；⑤ 30Y 回落至 5.23%（暂离 5.30% 失效线）。**但概率仍 30% 因：伊朗明确否认谈判 + 拒绝海峡提议 + 雷扎伊强硬 = 地缘随时反转（八次循环）；9 月加息 73.6% + ISM 55.6 强劲 + ECI 0.9% = 加息预期未消；8/5 再融资公告 Q3 借款 +680 亿 = 长端供给压力；SPCX 8/6 解禁 $1160 亿 = 科技股尾部风险；VIX 16 严重低估尾部风险。**

- 假设 A：**约 0%，凯利中性，不建议启用方向性仓位**（但可持有已有道指多头）
- 假设 B：**正值约 5.5%，1/4 Kelly ≈ 1.4%（风险预算上限极低）**

### 实际建议

**假设 A（做多道指/价值篮子）：凯利约 0%，边际不支持新增方向性仓位。** 原因：
1. **盈亏比偏低（0.50）**：道指已创新高（上行空间 1.5-3%），止损空间（4-6%）是目标空间的 2 倍。油价下跌利好已部分消化；
2. **胜率约 50%**：Bear 30% 概率中道指下跌，8/4-8/7 密集验证 = 事件风险高；
3. **但可持有已有道指多头**：道指创新高 + 油价下跌 + 经济韧性 = 持有逻辑成立，但不宜追高。

**假设 B（做多黄金）：凯利微正（1/4 Kelly ≈ 1.4%），可考虑极轻仓配置。** 但需注意：
1. **仅在"美伊谈判破裂 + 伊朗报复性军事行动"确认后才启用**--若谈判维持薛定谔状态或实质突破，黄金可能继续震荡或回落至 $4,000-4,050；
2. **风险预算上限约 1.4%**，这是该方向可承受的风险预算上限，不是买入账户 1.4% 的机械指令。名义仓位需按止损距离（约 5%）折算：若止损 5%，则名义仓位约为风险预算 / 止损比例 = 1.4% / 5% ≈ 28% 账户名义价值。但考虑跳空风险和杠杆上限，实际名义仓位应远低于此；
3. **若 30Y 突破 5.30% 或 VIX 突破 25，凯利假设失效**--利率驱动回调可能使黄金先跌后涨，止损可能被跳空击穿。
