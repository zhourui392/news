### 一、美伊"八次叫停"循环：地缘溢价阶段性回落但反复风险极高

**定性**：中性偏多但高度不确定（地缘溢价回落利好风险偏好，但"停火"可信度极低）。

**关键事实**：
- 特朗普美东时间周六晚宣布，应沙特、阿联酋、卡塔尔和伊朗请求，取消对伊朗新一轮大规模打击，称霍尔木兹海峡"已有协议"、无核化"也将达成"，谈判将于美东时间周日下午（北京时间周二上午）开始。
- 金十统计：这已是美伊冲突五个月来**第八次**"威胁大规模打击-临时撤回"循环（4/7、4/21、5/18、6/11、6/17、7/7、7/27、8/1），成为冲突显著特征。
- 信号高度矛盾：以色列第 12 频道称伊朗外长同意卡塔尔+美国提出的重开海峡方案，但伊朗法尔斯通讯社随后否认、称"纯属谣言"，外交部发言人强调海峡"永远不会恢复战前状态"，与阿曼谈判"与海峡开关无关"。
- 伊朗革命卫队声称打击巴林亚马逊数据中心（称其承担美军情报/云计算支持），并宣称摧毁 3 架美军 F-35（美方未回应）。以色列官员对特朗普一周内第二次反转感到沮丧，认为其倾向达成协议而非升级。
- 分析师普遍认为：双方立场尚未松动，更广泛冲突风险仍在，但最新进展为外交争取了更多时间。

**对 A 股传导**：① 地缘缓和 -> 避险情绪消退 -> 风险偏好修复 -> A 股开盘偏多；② 油价暴跌 -> 通胀预期下行 -> 中下游成本缓解（航空/化工/物流偏多），能源股偏空；③ 但八次循环意味着"停火"随时可能反转 -> 油价下跌和风险偏好修复的持续性存疑 -> 市场倾向于"买预期、卖事实"或快速轮动，**不宜将短线反弹线性外推**。对军工板块：地缘缓和短期偏空，但"八次循环"意味着冲突根本未解决，中期军工订单逻辑不变。

**关键事实**：

**对 A 股传导**：① 油价暴跌 -> A 股航空/运输/化工/物流板块成本缓解（偏多）；② 能源股（中国石油/中国石化/中国神华）支撑减弱（偏空）；③ SC 原油主力 7/31 已跌 4%，周一大概率继续跟跌 -> 国内能化产业链偏弱；④ 若油价持续低位，可缓解通胀预期 -> 降低美联储加息理由 -> 间接利好全球估值锚 -> A 股高估值成长股受益。但前提是霍尔木兹真正恢复通航，当前不可线性外推。

## 为什么会有影响（因果链）

### 1. 外盘溢出链：油价暴跌 + 美日干预 + KOSPI 回落 -> A 股震荡分化

周末三条外盘线索对 A 股方向相反：① 油价暴跌 8%（特朗普叫停对伊打击）-> 通胀预期下行 -> 中下游成本缓解 -> A 股航空/化工/物流偏多；② 美日联合干预日元 -> 美元偏弱 -> 人民币偏强 -> 北向资金回流预期 -> 蓝筹/消费受益；③ 但 KOSPI 7/31 暴涨 18% 后 8/3 即回落 5% + ECI 超预期（9 月加息概率 73.6%）-> 全球半导体反弹持续性存疑 + 高估值成长股承压。三条线索净效应为**中性偏多但分化**：蓝筹/价值（沪深 300）受益于油价回落 + 美元偏弱，成长/科技（创业板/科创 50）受 KOSPI 回落 + 加息预期压制。

### 2. 地缘缓和链（但有反复风险）：特朗普八次叫停 -> 油价跌 -> 风险偏好修复

传导路径：特朗普第八次叫停对伊打击 + 宣布 8/3 谈判 -> 地缘风险溢价阶段性回落 -> 油价暴跌 8% -> 通胀预期下行 -> 中下游成本缓解 -> A 股中下游板块偏多。**但八次循环是核心风险**：伊朗法尔斯通讯社否认海峡协议、外交部强调"永远不会恢复战前状态"、革命卫队仍在打击美军设施、以色列保持高度警戒 -> "停火"可信度极低。这意味着油价下跌和风险偏好修复的持续性存疑，市场倾向于"买预期、卖事实"。**不宜将短线反弹线性外推**，若美伊谈判破裂或伊朗再次强硬，油价可能 V 型反弹。

### 3. 政策预期链：央行"适度宽松" + 融资余额转正 -> 内部政策底延续

传导路径：央行下半年工作会议"继续实施适度宽松的货币政策" + 下调结构性工具利率 + 增加科技创新再贷款 -> 流动性环境改善 -> 利率敏感型板块（地产/券商/银行）受益 + 科技创新板块催化。融资余额 7/31 转正 +46.58 亿（终结三日 -919 亿）-> 杠杆去化接近尾声 -> 超跌反弹条件下杠杆可能回流。但 7 月 PMI 49.2%（荣枯线下）-> 内需仍有待企稳 -> 周期/消费板块承压。高技术制造业 PMI 53.3% -> 科技/高端制造结构性亮点延续。**政策底 + 资金面信号延续，但 macro 基本面偏弱限制反弹力度。**

### 4. 汇率与中美利差链：美日干预 -> 美元偏弱 + 人民币偏强 -> 北向资金回流

传导路径：美日联合干预日元 -> 美元偏弱（USD/JPY 跌破 156）-> 人民币偏强（USDCNH 6.72-6.76）-> 中美利差走阔压力缓解 -> 北向资金回流预期 -> 蓝筹/消费受益。**但日本减持 960 亿美元美债**（3 个月）-> 抛售美债推高收益率 -> 全球长久期资产折现率上行 -> A 股高估值成长股仍承压。两条链条方向相反，净效应取决于干预力度与日债抛售节奏的相对强弱。若美元/日元继续下行（跌破 155），美元偏弱占主导 -> A 股偏多；若美债收益率因日债抛售而突破 5.2%，利率压制占主导 -> A 股高估值承压。

### 5. 半导体趋稳链（但有反复）：KOSPI 暴涨后回落 + AI"交易底初现" -> 反弹持续性存疑

传导路径：7/31 KOSPI 创纪录暴涨 18% + SOX 反弹 -> A 股半导体超跌反弹（创业板 +3.06%）-> **但 8/3 KOSPI 即回落 5%** -> 全球半导体反弹持续性存疑 -> A 股科创 50/创业板面临获利回吐。机构判断（中金/广发/华泰）：AI 链"交易底初现"，调整空间已充分、杠杆资金已部分出清，但趋势性反弹需等 8 月下旬（中报 + 英伟达财报 + 赎回压力）。**当前更适合"等待确认而非左侧追多"**。长鑫 LPDDR6 + 先进封装/玻璃基板（TCL 华星下半年展示样品）提供主题催化，但不足以驱动趋势性反弹。

### 6. 产业景气链：新能源车销量亮眼 + 油价回落 -> 新能源/中下游偏多

传导路径：比亚迪 7 月销量 41.9 万辆创新高（海外近 18 万）+ 零跑突破 10 万 + 蔚来 +71% -> 新能源车产业链景气延续 -> 电池/零部件/锂电设备偏多。油价暴跌 -> 燃油车使用成本下降 -> 对新能源车替代逻辑有短期扰动，但新能源车已进入"成本优势 + 政策支持 + 海外扩张"的正循环，油价短期波动不改变中期趋势。充电桩 CCC 认证强制实施 -> 充电桩/储能板块利好。
