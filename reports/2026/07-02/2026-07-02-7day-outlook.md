## 5. 情景树（base / bull / bear）

> - "软就业 = 鸽派重定价" 已从 Bull 边缘条件升级为**基准情景核心驱动**；
> - Bear 需要更强大的触发因子（ISM 滞胀或银行危机或地缘失控）；

## 10. 凯利仓位校准（风险预算上限，非交易信号）

> 凯利在此仅用作"仓位刹车 / 风险预算上限"，不是机械买卖指令。胜率 p 由第 5 节情景概率解释性合成，G/L 来自本报告价格与失效条件假设，均为约数与区间。

**交易假设 A：ISM 服务 PMI 确认降温 + FOMC 偏鸽后，分批做多大盘科技 ETF（QQQ 或 XLK）**
- **方向**：做多；**适用前提**：07-07 ISM 就业分项 <52 且物价 <55；07-08 FOMC 措辞明确偏鸽或中性偏鸽；07-03 半导体未加速下跌（闪迪跌幅收窄至 <2%）。对应 Base 内偏多路径（55% 中约 30pp 有利）+ Bull（28% 中约 20pp 兑现该方向）。
- **胜率估计 p ≈ 0.55**（55% Base 中 30pp + Bull 20pp = 50pp / 93pp 总有利度）；败率 q ≈ 0.45。
- **目标收益 G ≈ +4%~+6%**（纳指填补 07-02 -0.8% 缺口 + 延续反弹 3-5%），止损 L ≈ **-2.5%**（纳指跌破 07-01 收盘对应值 25832 -2.5% = 25187 或 QQQ 跌破对应位）。**盈亏比 b ≈ 1.8**。
- **原始凯利 f\* = (b×p − q)/b = (1.8×0.55 − 0.45)/1.8 = (0.99 − 0.45)/1.8 ≈ 0.30**（30% 风险预算上限）。
- **实际建议：≤1/4 Kelly ≈ 7.5% 风险预算**；ISM 服务和 FOMC 落地前**不启用**凯利。仅可在 07-08 收盘后按 1/8 Kelly ≈ 3.75% 试探。

**交易假设 B：轻仓做多黄金（现货 / GLD / 黄金 ETF）**
- **方向**：做多；**适用前提**：4100-4120 入场（不追高）、DXY 守稳 100.8 以下、10Y 不破 4.55、ISM 就业分项不 >55、中东无重大升级。
- **胜率估计 p ≈ 0.55**（Bull 28pp + Base 55pp × 0.6 有利度 ≈ 61pp / 100pp）；败率 q ≈ 0.45。目标 G ≈ +4%（4250 附近）、止损 L ≈ **-2%**（4020 破位）。**盈亏比 b ≈ 2.0**。
- **原始凯利 f\* = (2.0×0.55 − 0.45)/2.0 = (1.10 − 0.45)/2.0 ≈ 0.325**（32.5% 风险预算上限）。
- **实际建议：≤ 1/4 Kelly ≈ 8% 风险预算**；但当前 4100-4120 紧挨非农后回吐区——**建议等 4050-4080 回踩再动用一半预算**（约 4%），剩余预算留给 07-08 后。

**风险预算 vs 名义仓位**：以上 f\* 是"该方向可承受的风险预算上限"（即愿为此方向承担的最大回撤占账户比例），**不是买入账户某百分比的机械指令**。换算名义仓位须按止损距离折算：名义仓位 ≈ (风险预算 × 账户) / 止损百分比。例：假设 A 中 7.5% 风险预算 / 2.5% 止损 → 名义敞口约为账户的 3.0 倍（意味着若使用 1x 现货 QQQ 就已用光风险预算，**必须使用期权或半仓杠杆**）。
