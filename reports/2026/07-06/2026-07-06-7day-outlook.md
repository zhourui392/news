## 3️⃣ 当前主线综合判断

### 主线 1：美联储与美元 —「鹰派回潮，但市场定价偏鸽」
- **方向**：轻度利空（对美股估值构成压力）
- **强弱程度**：中强
- **最近一周一致性**：一致。Fed Governor Waller 鹰派言论 + ISM 服务业价格分项仍在 67.7 + CFTC 美元净多头升至 2015 年最高 + 30 年美债重返 5%。但 CME 定价仍显示 7 月维持不变、9 月可能降息——市场与聯储信号分歧。
- **对哪类消息最敏感**：7/8 FOMC 纪要（首次反映沃什主持下的内部讨论）、7/13 CPI、沃什公开讲话。若纪要出现"仍需加息一次"措辞，美债和美元将急升、美股估值压缩。

### 主线 2：中东地缘 / 油价 —「和平红利已在定价，但脆弱」
- **方向**：中性偏利（油价下行 → 通胀回落 → 对美股整体偏多）
- **强弱程度**：中强
- **最近一周一致性**：一致。OPEC+ 8 月增产 + 沙特 26 年来最大降价 + 马士基/赫伯罗特恢复红海航行 + 八艘三井船只驶离霍尔木兹 → WTI 跌破 68.50。但伊朗否认 7 月 6 日谈判，特朗普称"要么达成协议要么完成任务"——和谈脆弱。
- **对哪类消息最敏感**：7 月 11 日和谈节点、伊朗任何核设施重启信号、新的油轮遇袭或航道封锁。

### 主线 3：AI / 半导体盈利 —「最强边际增长极」
- **方向**：明确利多
- **强弱程度**：强
- **最近一周一致性**：高度一致。高盛上调 AMD 43%、Sandisk 83%、WDC 63%；SK Hynix 280 亿美元 ADR IPO 超额认购、Baillie Gifford 锁定 70 亿美元；三星 Q2 DRAM 提价 20%；SEMI 存储晶圆设备投资首破 500 亿美元；Anthropic 自研 AI 芯片 + 美光日本 90 亿美元扩产。费城半导体单日涨 3%。但摩根士丹利警示资金将从芯片转向超大型云商。
- **对哪类消息最敏感**：SK Hynix 7/10 定价反馈、纳斯达克开盘半导体板块强度、博通/苹果延长合作后续。

### 主线 4：银行 / 财政 / 政策 —「中性偏结构」
- **方向**：中性
- **强弱程度**：中
- **最近一周一致性**：分歧。特朗普力推"特朗普账户"（早期投资补贴）；关税政策推动丰田 36 亿美元德州建厂 + 外资回流；但美银数据称美股三个月来最大资金流出。台湾依赖中东 LNG 进口暴露航道风险。
- **对哪类消息最敏感**：关税/贸易法案进展、德法财政信号、美债拍卖需求。

### 主线 5：贵金属 / 避险 —「调整而非转势」
- **方向**：震荡偏弱
- **强弱程度**：中弱
- **最近一周一致性**：一致回调。黄金从 4200 跌至 ~4133 后反弹至 4176；白银跌破 60 后反弹至 62.46。风险偏好回升 + 美指走强压制，但 CFTC 黄金净多头仍高企 + 央行购金叙事未破。以色列央行降息至 3.5%、美伊和谈削弱避险溢价。
- **对哪类消息最敏感**：实际利率变化、央行购金数据、地缘突发事件。

## 5️⃣ 情景树

### 基准情景（Base Case）— 概率 50%

- **触发条件**：7/8 FOMC 纪要偏中性（承认通胀下行但未排除进一步行动）；7/13 核心 CPI +0.25%；美伊 7/11 谈判维持"框架 + 继续接触"但无突破性制裁豁免；WTI 守住 66-68 美元区间。
- **权重依据**：最具惯性的路径——市场已部分定价加息风险但未恐慌，经济软着陆叙事仍在，AI 盈利季风尚不能判断见顶。
- **各资产方向**：
  - 道指 → 震荡偏多（52,000-54,000）
  - 标普 500 → 小幅上行（7,500-7,750）
  - 纳指 → 跑赢其他（25,500-26,800），半导体继续领涨
  - 美元 → DXY 100-102 区间震荡
  - 美债 → 10 年期 4.35-4.65% 区间
  - 原油 → WTI 65-70 区间偏弱
  - 黄金 → 震荡偏弱（4,050-4,250）
- **失效信号**：CPI >0.4% + 纪要鹰派；或美伊谈判正式破裂 + 霍尔木兹再封锁；或 30 年期美债突破 5.25%。

### 牛市情景（Bull Case）— 概率 25%

- **触发条件**：7/8 纪要确认委员会主流认为"当前利率具限制性，无需进一步行动"；7/13 核心 CPI 月率 ≤+0.15%；7/11 美伊公开可验证的制裁解除备忘录；SK Hynix 定价后首日大幅跑赢。
- **权重依据**：通胀回落速度 + 央行转向迹象 + 地缘缓和三重顺風同时具备时才能驱动。
- **各资产方向**：
  - 道指 → 上攻 55,000+
  - 标普 → 冲击 7,800-8,000
  - 纳指 → 加速上扬至 27,500+
  - 美元 → 走弱至 98-99
  - 美债 → 10 年回落至 4.00-4.20%
  - 原油 → 突破 72（但供应压力限制上方空间）
  - 黄金 → 中性（4,150-4,300），避险资金并未大规模撤离但缺少新入催化剂
- **失效信号**：核心 CPI 超预期 / 突发的重大地缘升级事件（如伊朗重启 60%+ 铀浓缩）。

### 熊市情景（Bear Case）— 概率 25%

- **触发条件**：7/8 纪要中出现多数委员支持"年内仍需加息 1 次"措辞；7/13 核心 CPI >0.35%；美伊谈判破裂伴随伊朗重启 20%+ 浓缩；30 年期美债突破 5.25% 引发资金成本恐慌。
- **权重依据**：通胀粘性 + 政策滞后效应 + 季节性因素（Q3 通常是风险资产高波动期）。
- **各资产方向**：
  - 道指 → 回调至 50,000-51,000
  - 标普 → 急跌 7,200-7,350
  - 纳指 → 受估值压缩冲击最大，24,000-24,800
  - 美元 → 急升至 103-105
  - 美债 → 收益率全面急升（10 年突破 4.80%）
  - 原油 → 暴涨至 78-85（航道风险重燃）
  - 黄金 → 突破 4,300-4,400
- **失效信号**：7/13 CPI 意外降至 +0.12% 以下 / 美联储某委员提前发出"数据依赖 + 暂缓加息"信号 / 霍尔木兹全面通航 + 伊朗宣布自愿暂停核计划。

## 🔟 凯利仓位校准（风险预算上限，不是交易信号）

> ⚠️ **核心定位重申：** 凯利公式仅作为仓位刹车/风险预算校准模块使用，不构成机械买卖信号。

### 交易假设 A：确认利率见顶信号后，轻仓做多纳斯达克 100（QQQ / NQ 期货）

| 项 | 估计值 | 说明 |
|---|---|---|
| 方向 | 做多 NQ | 前提：7/8 纪要中性偏鸽 |
| 胜率 p | 约 50% | 基于 Base Case 概率合成 |
| 败率 q | 50% | 1-p |
| 目标收益 G | 8% | 基于 Base Case 纳指上行空间 26,000 → 26,800；乐观情景 27,500 |
| 止损损失 L | 4% | 基于失效信号纳指跌破 25,000（回吐 7/6 全部涨幅） |
| 盈亏比 b | 2.0 | G/L = 8%/4% |
| **原始凯利 f*** | **25%** | f* = (bq - q)/b = (2×0.5 - 0.5)/2 = 0.25 |
| **实际建议** | **1/4 Kelly ≈ 6.25%** | 宏观数据+纪要+财报多重不确定性叠加 |

**风险预算上限**：账户净值的 6.25%（非买入金额）。**名义仓位**按止损距离折算：若买入位 26,000，止损位 24,960（-4%），止损距离 ~1,040 点；则名义头寸 = 账户净值 × 6.25% ÷ 1,040 点。
