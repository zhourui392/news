## 重点内容（主题化）

### 1）AI / 半导体 / 光通信链条全球同步抛售 — 利空，强度强
- 周五 A 股创业板 -4.07%、科创 50 -4%+、深证成指 -3.44%、沪深 300 -3.03%、4600+ 只个股下跌。寒武纪 -5%（成交破 100 亿）、宁德时代 A 股 -5% / 港股 -6%；港股芯片 / 存储 / 光通信集体重挫。
- 全球链条联动：6/26 SOX -5.29%、SK 海力士 -8.4%、台积电 -2.1%、ASML / ASM 国际跟跌；美光、高通虽有大行上调目标价（大摩 1200 美元、巴克莱 2000 美元），但当日依然 -6.6% / -7%。
- **原因不是基本面坏**：美光长协利好（长期协议削弱周期波动、市值短暂超越 Meta 和特斯拉）刚发酵就被苹果 Mac/iPad 涨价 16%–25%、微软 Xbox 涨价、内存 / SSD / 显卡终端涨价 → "AI 资本开支 → 终端被迫加价 → 需求弹性受疑"的成本反噬叙事接管。叠加 EPFR 数据科技板块单周净流出 93 亿美元创历史最大。
- A 股内的结构性逆势点：**多氟多半导体级氢氟酸涨价 20–30% 供应台积电 / 长鑫存储**；**国产光刻机概念逆势活跃**（海立股份涨停、新莱应材 20cm 涨停）；**算力链 + 国产 GPU**（宏川智算与长兴半导体 DDR5 内存条交付国内头部 GPU 设计厂商）。**国产替代叙事仍在但被外盘抛售压制**。
- 周一 A 股大概率**继续承压**，但分化会加剧：纯外资定价的港股 + AH 个股 跟跌幅度更大，纯内需 / 国产替代 + 有真实订单 / 价格的细分（半导体材料、光刻机零部件、HBM 配套）跌幅较有限。

### 2）央行流动性 + 隔夜逆回购新工具 — 利多，强度中等
- 央行 6/26 净投放 2315 亿元（7 天逆回购，利率 1.40%），**本周累计净投放 5297 亿元**；本周开展 5000 亿元 1 年期 MLF 操作（对冲 3000 亿到期，净投放 2000 亿）。
- **新工具落地**：央行 6/26 早间公告，**将在 6 月 29 日、6 月 30 日公开市场操作中增加隔夜逆回购操作品种**。这是货币政策操作框架的边际优化：隔夜利率走廊机制的丰富意味着央行对短端利率的精准调控能力提升，**降准 / 降息以外多了一层柔性工具**。
- 离岸 HIBOR 一周期升至 1.70%（5 个月新高）反映**短期人民币流动性边际收紧**，但央行净投放 + 工具升级提供对冲。
- 对 A 股的传导：流动性宽松 + 工具升级利好高股息 / 银行 / 大盘价值（沪深 300、上证 50 含权重银行保险），对成长股估值帮助有限（成长股更依赖风险偏好）。
- **下周关注**：6/29、6/30 隔夜逆回购的实际投放规模和利率定价。

### 3）中美经贸"对等降税"路径 + 关税博弈升级 — 中性偏多（但波动信号）
- 商务部回应中美经贸磋商：**双方同意成立贸易理事会**，并将在理事会项下讨论对等降税等合作。这是 5 月日内瓦谈判路径的延续，**对外贸链 / 跨境电商 / 港口物流是结构性利多**。
- 但同步存在**关税博弈风险**：特朗普 6/27 凌晨威胁对征数字服务税的欧洲国家加征 100% 关税；美国 5 月商品贸易逆差扩大 27.4% 至 1058 亿美元（市场预估 -850 亿），出口降 5.4% / 进口升 3.6%；欧盟拟 9/9 起对铝废料出口征 15% 关税。
- A 股传导：**结构性而非系统性**。出口链（家电、消费电子、纺织）受益于"中美对等降税"框架；新能源车 + 锂电（中欧持续摩擦）仍承压；铝相关有色 + 再生资源（欧盟新政策）可能短线扰动。

### 4）地产 + 保障性住房 + 内需政策 — 利多，强度中等
- 周五 A 股房地产板块**逆势异动拉升**：万科 A +5%、合肥城建 / 张江高科 / 荣丰控股 +6%+、盈新发展涨停。港股地产板块同样逆市涨。
- 政策信号：① **河南到 2030 年新增保障性租赁住房 5 万套以上**（《关于推动城市高质量发展的实施方案》）；② **税务总局换购住房个税政策延续至 2027 年底**；③ 国务委员谌贻琴在江西调研"坚决落实就业优先战略"；④ **特朗普拒签美国住房法案并喊话降息**（间接利好全球地产估值）。
- 高盛中国宏观团队：**中国居民股票配置相对其长期潜力仍较低**，房地产财富积累作用减弱 + 低存款利率 → 储蓄向股票和保险转移是中期主线。
- **国家能源局：十五五全国电网固定资产投资达 5 万亿元以上**——电网设备 / 特高压 / 输变电 / 配电 / 智能电网 是下半年新的财政发力主题。

### 5）金融监管 + 退市 + ST 风险事件 — 局部利空
- **证监会查处玖瀛资产、腾创投资**（私募基金违法违规）；荃银高科因 2024 年年报虚假记载 6/30 起变 ST 荃银；ST 金鸿顺被立案；*ST 赛隆 6/26 起退市整理期；上交所本周对长盈通、中船特气、昀冢科技异常波动股票及高溢价 LOF 重点监控。
- **影响**：高估值小盘 + ST + 题材股个股风险溢价上升；中央结算公司将做市商现券交易结算费从 8 折降至 7.5 折，对**国债市场流动性 + 银行间做市商**有边际利多。

### 6）黄金 / 贵金属 — 双向极度敏感
- 上海黄金交易所黄金 T+D 6/26 收涨 1.1% 报 882.84 元/克；晚盘进一步涨 1.46% 报 890.1 元/克。

- **机构调仓**：招商银行 7/27 后停办"招财金"业务；中信银行 6/30 后调整黄金 T+D 保证金比例；多家投行下调远期目标价（华侨 5350→5100、花旗 3M 4000、高盛年底 5400→4900、德银 Q3 4300、麦格里年底 4300、凯投宏观年底 3500）。

- **结论**：金价 4000 美元附近反复争夺，国内贵金属股 + 黄金 ETF + 上金所做市商相关标的**适合波段、不适合趋势重仓**；美军袭伊后周日晚电子盘大概率跳空向上。

## 为什么会有影响（因果链）

**链 1：外盘抛售 → 北向 / 港股 → A 股核心资产估值锚**
SOX -5.29% + 港股科技 -3.41% 已经把"AI 估值溢价"消磁了 3–5%，A 股芯片 / AI / 光通信 / HBM 板块周一开盘**先按 -3% 至 -5% 定价**是基础情景。压力传导路径：美股 SOX → 港股科技 → A 股 AH 个股（中芯、宁德、寒武纪、智谱 等）→ 纯 A 股科创 / 创业板。

**链 2：地缘事件 + 油价跳空 → 通胀预期 + 风险偏好**
美军袭伊若周日晚 WTI 跳空至 75 美元以上，**A 股将看到能源 + 油运 + 军工补涨 + 航空航运承压**的二元分化。若 WTI 跳空 < 4 美元且周一回吐，则地缘冲击仅一日跳空、整体不破区间。

**链 3：央行新工具 → 短端利率 → 价值 + 红利风格**
6/29、6/30 隔夜逆回购品种新增是**结构性利好**：① 直接稳定短端流动性；② 提升央行调控精度；③ 暗示货币政策框架升级（但**非降准信号**）。这对**银行、保险、白酒、煤炭、电力公用**这类高股息红利风格有边际利好；对成长 / 科创板帮助有限。

**链 4：中美贸易理事会 → 出口链 + 关税相关板块**
"对等降税"是 5 月日内瓦框架的延续 + 实操化。利好结构：**家电（美的、海尔）→ 跨境电商 / 物流 → 部分纺服 → 部分电子代工**。对新能源车 / 锂电 / 太阳能（仍有补贴 / 关税摩擦）帮助有限。

**链 5：人民币 + 利差 → 北向 / 港股 → AH 折价**
USDCNY 6.7997 + 离岸 HIBOR 一周期 1.70% 5 月新高 → **美元兑人民币跌空间被打开**。若美军袭伊后 DXY 跳升至 102+，人民币将再次承压、北向加速流出。**人民币是最敏感外部锚**。

**链 6：地产 + 保障房 + 财政 → 地产链 + 周期 + 银行**
河南保障性租赁住房 + 税务总局换购个税延续 + 美国住房法案僵局 → A 股房地产板块周五已经率先走强（万科 +5%）。地产 + 银行 + 建材 + 家居一体化的**地产链反转交易**适合用作"对冲半导体抛售"的另一边。

**链 7：估值 + 情绪 → 北证 50 + 小盘独立**
北证 50 周五逆势 +2%、戈碧迦 +22%，反映**资金风格转换**：当外盘冲击 AI / 半导体大盘股时，**纯内需小盘 + 北交所主题资金独立运行**。

## 情景树（base / bull / bear）

> 前提：基于美军 6/26 20:32 UTC 后袭伊事件的初步判断（**有限范围打击 + 6/28–29 美伊技术谈判存续 + 伊朗未立即对等回应**）。若周末事件升级，需把概率重新分布，bear 上调至 45–55%。

### Base：高波动震荡、分化加剧、整体偏空但不崩盘（50%）

**触发条件**
- 周末美军行动限定一次性，伊朗以言辞回应 + 6/28–29 谈判维持或延期但未取消；
- 周一 A 股 AI / 半导体早盘大跌 -3% 至 -5%，午后红利 + 银行 + 地产 + 内需对冲，全天上证收 -1% 至 -1.8% 之间；
- 6 月 PMI 在 49.5–49.9 区间，未破 50 但未继续下滑；
- 央行新增隔夜逆回购规模合理（500–2000 亿）+ 利率不超 1.40%；
- 沃什讲话维持"嘴硬不动手"基调；ISM PMI 不破 56 / 物价分项不破 84；
- USDCNY 在 6.78–6.81 区间震荡。

**主观概率：50%**

**资产方向**
- 沪深 300：4750–4900（-2.5% 至 +0.5%）
- 创业板指：4050–4250（-2% 至 -5%）
- 北向资金：单周净流出 -50 至 -120 亿
- USDCNH：6.78–6.81 区间偏弱

**失效信号**
- 美军继续大规模打击伊朗或伊朗对等报复 → 进入 bear；
- 6 月 PMI 站上 50 + 央行下调短端利率 + 美光 / 高通机构集中 reiterate buy → 接近 bull；
- 沃什明显鹰派 + ISM PMI > 56 + USDCNY 破 6.83 → 加速向 bear 倾斜。

### Bull：地缘快速降温 + 国内数据修复 + 央行宽松确认（22%）

**触发条件**
- 周末美军行动不扩大、伊朗象征性回应、谈判按计划进行；
- 6 月 PMI 重回 50 上方（关键阈值），社融 / 信贷 / 工业增加值等高频数据走强；
- 央行 6/29、6/30 隔夜逆回购利率定在 1.30–1.35%（暗示边际宽松）；
- 美光 / 高通 / 博通在周一 / 周二集中获得机构 reiterate buy、SOX 量价配合止跌；
- 沃什讲话偏鸽 + ISM PMI 温和走弱；
- 中美经贸理事会发布第一批"对等降税"实质性清单。

**主观概率：22%**（较中性下调，因为美军袭伊给概率加权打折）

**资产方向**
- 沪深 300：4900–5050（+0.5% 至 +3.7%）
- 创业板指：4250–4500（+1% 至 +7%）
- 北向资金：单周净流入 +30 至 +100 亿
- USDCNH：6.75–6.78（人民币走强）

**失效信号**
- 美军袭伊后续事件超预期升级；
- 6 月 PMI 跌至 49.3 以下；
- 沃什鹰派 + ISM PMI 强劲；
- 半导体板块出现新的负面催化（如台积电下调全年 capex）。

### Bear：地缘升级 + AI 抛售延续 + 数据偏弱 / 偏鹰双杀（28%）

**触发条件**
- 美军继续大规模打击伊朗本土多目标 / 伊朗对等报复（袭击沙特、UAE 设施）/ 6/28–29 谈判取消；
- WTI 跳空稳定站上 80 美元 + 布伦特上 82 美元；
- 6 月 PMI 跌至 49.0 以下；
- SOX 周一 / 周二再跌 3%+、击穿 50 日均线，A 股 AI / 半导体 / 光通信 / 算力链条恐慌出清；
- 沃什明显偏鹰、ISM PMI > 56 + 物价分项 > 84；
- 中美关税战意外升级（特朗普执行 100% 数字服务税关税威胁）；
- USDCNY 急速破 6.83。

**主观概率：28%**（较中性上调，因为美军袭伊为 bear 直接加权）

**资产方向**
- 沪深 300：4650–4800（-5% 至 -1.5%）
- 创业板指：3900–4100（-7% 至 -2%）
- 北向资金：单周净流出 -150 亿 以上
- USDCNH：6.82–6.86（人民币加速贬值）

**失效信号**
- 美军行动结束 + 伊朗象征性回应 → 转 base；
- 国内央行降准降息或加大公开市场净投放 → bear 缓和；
- 6 月 PMI 意外站上 50.5 + 中美贸易理事会突破。

> **概率权重依据**：① 美军袭伊在 7 天窗口内的尾部风险已部分实现，权重从 25% 上调至 28%（bear）+ 把 base 概率从 45% 上调至 50%（覆盖更宽幅震荡）；② Bull 概率从 30% 下调至 22%，因为外盘 AI 抛售扩散叠加地缘对 7 天窗口内强反弹的门槛抬高；③ 北证 50 与主板分化已经发生 → 不再假设全市场同涨同跌。
